# Política de Privacidade — vods app

Última atualização: 21/11/2026

O **vods app** é uma ferramenta de uso pessoal do dono da conta de cortes. Esta política explica quais dados ele usa.

## Dados usados
- **Da conta do TikTok que autorizou o app:** o identificador da conta (*open_id*) e os tokens de acesso fornecidos pelo TikTok no login.
- **Nenhum dado de outros usuários** do TikTok é coletado.

## Para que são usados
- Exclusivamente para enviar à própria conta autorizada os vídeos que o dono escolheu publicar (título, legenda e créditos).

## Onde ficam
- Os tokens ficam salvos **apenas no computador do dono**, em um arquivo local. Nada é vendido, compartilhado ou enviado a terceiros.

## Como apagar
- Revogue o acesso em: TikTok → Configurações e privacidade → Segurança → Apps e serviços.
- Os dados locais são apagados ao excluir o arquivo de tokens do computador.
